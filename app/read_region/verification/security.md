Local service images are normalized PNG bytes held in bounded RAM; native worker input/output lives in a private temporary directory until worker completion/deadline. A single owner lock rejects multiple service owners. Durable SQLite stores only SHA256(scope + NUL + execution), expiration, revoked state and budget counters; no pixels, OCR text, filename or credential. Startup revokes prior ledger entries. Deleted/expired execution IDs cannot be registered again; the bounded 100,000-entry ledger fails closed when full and needs an operator-managed replacement instance after all old execution contexts are retired. Keep state volume across restarts; do not reset it to bypass budgets.

Default TTL is 15 minutes from first registration attempt, unchanged by read/additional registration. Sweeper runs every 30 seconds; authorization expires immediately. In-flight native work is bounded to 45 seconds including decode; OCR to 30 seconds. Response reauthorization prevents delete/expiry races. Private worker temporaries are removed by the parent even after kill. A filesystem deletion does not establish physical media erasure; swap/core dumps/backups need deployment controls.

Plugin file and OCR calls use configured HTTPS origins and literal IP pins, TLS certificate verification and original hostname SNI. No DNS/proxy fallback or redirects; file path restricted to /files/... and traversal/double-encoding rejected. Link-local/multicast/unspecified IPs prohibited; exact approved private Dify addresses may be configured by operator. Never choose addresses by guessing. Dify SDK File.blob is deliberately unused because SDK0.10.2 fetches arbitrary URLs via httpx.get. Service API has no URL or path fetch input.

The plugin default context resolver raises CONTEXT_REQUIRED before I/O. No conversation/session/message substitute, execution form field, environment bypass or static execution ID exists. Typed context injection is exercised only by local adapter tests; it does not establish stock Dify integration.

Service command disables access/error trace logs; safe structured errors use request_id and fixed codes. Unit canaries cover self-service paths only. Actual reverse proxy, Dify logs, provider retention, external observability, swap/backups, endpoint TLS routing and native DNS/socket attempts are unverified. Docker network-none proves local OCR succeeds without external connectivity; it does not prove no attempted connection across all startup/error/restart paths. Dify receives OCR content and may send it to the existing LLM. Deleting service data does not delete these copies. No production confidential data acceptance is claimed.
