# Local region OCR: source-bounded implementation notes (2026-11-13)

- Tesseract official CLI documentation: https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html . Language lists, local tessdata, TSV word coordinates/confidence, OEM1 support a small CPU subprocess adapter. TSV scores are engine scores, not calibrated correctness probabilities. Explicit tessedit_create_tsv=1 avoids reliance on a config file under a custom model directory. Runtime version is checked against5.3.0; model bytes are hash-verified from tessdata_fast4.1.0 commit65727574dfcd264acbb0c3e07860e4e9e9b22185. License and sources are in app/read_region/models.lock.json. This is an alternative to the design's PaddleOCR candidate, chosen for bounded local deployment; no Japanese engine superiority is established.
- Pillow official Image/ImageOps APIs: https://pillow.readthedocs.io/en/stable/reference/Image.html and https://pillow.readthedocs.io/en/stable/reference/ImageOps.html . Crop/resize/exif_transpose inform the geometry pipeline. Limits, Decimal boundaries, authorization and deadlines are application controls, not Pillow defaults. Pinned runtime13.0.0 after local dependency audit identified advisories in12.3.0. Tests exercise used APIs on13.0.0.
- OWASP SSRF guidance: https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html . Apply origin/path allowlisting, no redirects and literal approved IP pins with TLS hostname verification; do not globally forbid required private Dify endpoints or modify shared network policy. Native network attempts have not been traced.
- Dify SDK0.10.2 installed source dify_plugin/file/file.py: File.blob performs httpx.get on its URL, so this adapter does not invoke it. Plugin tool declarations and provider are validated using the actual installed SDK in a separate subprocess to avoid gevent monkey-patching service tests.
- Dify1.18 target trusted execution context: research owner is the parent; stock transport does not yet establish same-run stable context across fixed-node and Agent tools. Session/message/conversation IDs are not substitutes. The shipped plugin deliberately refuses all three calls before I/O. Runtime-injected test context is a local adapter test only.

Scope: public-safe mechanism/evidence; no original handoff, customer image, URL signature, credential, private environment or Chatflow export is copied. Real synthetic OCR verifies local execution, not actual deployment or representative quality. Retest dependencies, model/license/hash, network, geometry and quality after updates.
